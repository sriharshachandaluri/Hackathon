# Run Instructions

1.  **Backend:**
    Ensure you have `fastapi` and `uvicorn` installed:
    `pip install fastapi uvicorn`
    
    Run the backend:
    `uvicorn main:app --reload`

2.  **Frontend:**
    The frontend files (`index.html`, `style.css`, `script.js`) are served alongside the backend. You can open `index.html` directly in a browser after the backend is running to interact with the API.
